# 一个仓库研究一个人：系列复用规范

**系列名：人物研究计划 / People Research。单仓库命名：`<name>-research`。** 人物实例的名字是研究对象，不是其官方品牌，也不暗示其参与。

可共用方法、schema、模板、维护脚本与 Skill；不可直接共用人物结论和证据。本库是范冰实例，不是换名字就能变成另一人物的成品。

## 复用步骤

复制工具、规范和模板到新目录。保留本版目录约定，重写 README 与 `person.json`；清空全部 `data/*.json` 的人物记录及生成视图；删除原案例、模式、综述、对象卡、来源地图、更新记录中的范冰内容。命名用与对象能明确对应的拉丁字母短名，先做重名消歧。

重新写明对象公共身份、两条能够相互印证的身份入口、研究范围和不收录内容。来源不足时保留未知，不用同名搜索结果顶替。

第一轮只录少量认真读过的来源、一条有时间依据的事件和一个可回答问题。证据不足时不创建模式。然后重写综述、缺口与案例索引，运行全部检查。

**本版没有提供“一键把所有个人档案改名”的生成器。** 这是有意保留的人工审阅步骤，避免把范冰资料错贴给另一个人。

## 系列保持一致的部分

文件命名、来源状态、日期精度、事实/自述/推断的区分、模式反例、版权与隐私边界，以及同一套检查命令。不同人物可以有不同的作品类型、研究问题和材料规模。

## 系列不应强求的部分

不要求每个人都必须有创业失败、商业模式、可验证预测或十个金句；不要求全都产出一个可调用的人格模型。公开材料不足时，少而有出处比格式完整更好。

研究政治人物时继续遵循方法中的中立边界，不把系列做成人物排名或政治动员工具。
