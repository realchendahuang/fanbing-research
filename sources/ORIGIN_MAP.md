# 来源地图与旧博客线索

## 身份锚点

优先从本人介绍与互相链接的 GitHub 主页确认身份，再沿明确外链寻找具体作品。采访可作为补充，但履历回答仍是本人自述。[S001](cards/S001.md) [S002](cards/S002.md) [S026](cards/S026.md)

## 历史线索，而非当前所有权声明

资源页和回顾出现 `fanbing.net` 线索；2012 年文章与停止续费说明连接到“同步控”；2023 年迁移说明提供后来博客迁移背景。[S013](cards/S013.md) [S020](cards/S020.md) [S017](cards/S017.md) [S028](cards/S028.md) [S033](cards/S033.md)

这些只用于回溯作者明确公开的作品。旧域名可能换手；未知日期不可补造。不能把现在恰好位于某旧域名的站点自动归到范冰，也不恢复作者选择撤回的私人照片。

## 找旧文章的操作顺序

先从已确认文章中的原始链接与标题出发；再查合法公开存档或可信转载；逐条核对作者、日期、版本和上下文；只确认目录时登记线索，不生成正文摘要；确有存档才填写 `archive_url`。本轮没有已验证快照。
