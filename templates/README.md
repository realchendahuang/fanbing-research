# 研究模板

模板是填写规范，不属于人物事实，也不会自动进入数据。先阅读 [METHODOLOGY](../METHODOLOGY.md) 和 [DATA](../docs/DATA.md)。

| 模板 | 用途 |
| --- | --- |
| [source-card.md](source-card.md) | 阅读时记录出处、范围与限制 |
| [case-study.md](case-study.md) | 拆一个具体事件或作品 |
| [pattern.md](pattern.md) | 建立可被削弱的工作假设 |
| [prediction.md](prediction.md) | 登记明确可核对的原始预测 |
| [experiment.md](experiment.md) | 记录使用者自己的实践，而非人物业绩 |
| [update.md](update.md) | 一轮研究的真实完成范围 |

来源卡最终由 JSON 自动生成。手写模板可先作为 `local-only/` 的阅读草稿，再把确认信息加入规范数据。不要直接覆盖生成卡。
