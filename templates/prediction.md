# 预测登记模板（不是已发生记录）

只有原文包含可核对的断言与时间界限时才进入数据。引用应短且必要；复杂内容用忠实转述并给定位。

规范字段：

```json
{
  "id": "PR001",
  "claim_text": "待忠实记录的原始断言",
  "made_on": "2026-09-25",
  "horizon": "原文提供的验证时间界限，不自行编造",
  "test_rule": "怎样判断、所需资料及适用条件",
  "source_ids": [],
  "status": "unassessed",
  "assessment": null,
  "outcome_source_ids": []
}
```

上例日期只是格式示意，不得复制为真实记录。实际录入至少一个真实来源；验证时保留原始规则，不根据结局修改。无法明确核验的观点留在研究笔记。
