# 实验登记模板（不是执行结果）

规范字段：

```json
{
  "id": "X001",
  "title": "待命名",
  "pattern_ids": [],
  "status": "planned",
  "started_on": null,
  "design": "背景、目标、样本、操作和停止条件",
  "baseline": null,
  "result": null,
  "limitations": "已知局限与混杂因素"
}
```

按真实阶段填写 `planned`、`running`、`completed` 或 `abandoned`。已完成实验必须填写实际结果。个人数据只在必要、获许可且安全的情况下公开；默认用去标识汇总。
